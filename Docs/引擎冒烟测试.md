# SocioVerse2 引擎冒烟测试

本文档说明如何用**最简实验**验证本项目已正确接入真实 SocioVerse2 引擎
（而不是 `scripts/commshim.py` 提供的本地桩）。跑通一次即可确认：

- provider 注册（`asch.env` / `asch.pop` / `asch.decision` / `asch.collector`）能被引擎解析；
- `asch/bundles.py` 的四件套 schema 与已安装的 SocioVerse2 版本兼容；
- 引擎主循环（advance_to → observe → decide → apply → record）能完整跑完 18 个试次；
- DuckDB 轨迹库、面板行、指标行都能落盘。

> 本测试**不调用任何 LLM**（`--llm scripted`），也不产出可对外报告的行为结论；
> 它只证明"引擎接得上、能跑通"。真实模型运行请另用 `--llm openai` 并配置 `.env`。

## 1. 前置条件

- 一个已安装 SocioVerse2 的解释器。本机为可编辑安装：
  `/home/atwood/SocioVerse2`，其 `.venv` 内 `import socioverse` 可用（版本 0.2.0）。
- 刺激集已生成（仓库自带 `stimuli/`，74 张图 + manifest + answer_key）。
- 无需 API key（脚本策略不联网）。

两种让 `socioverse` 可导入的方式，二选一：

```bash
# A. 直接用 SocioVerse2 自带的 venv（推荐，无需额外安装）
SOCIOVENSE_VENV=/home/atwood/SocioVerse2/.venv

# B. 或把 SocioVerse2 以可编辑方式装进本项目 venv
.venv/bin/pip install -e /home/atwood/SocioVerse2
```

## 2. 跑最简实验（C0，1 个会话，脚本策略）

**不要**加 `--local-stub`：加了就会装本地桩，跑的不是真引擎。

```bash
cd /home/atwood/Agent-Asch-Conformity-Experiment

PYTHONPATH=/home/atwood/Agent-Asch-Conformity-Experiment \
  /home/atwood/SocioVerse2/.venv/bin/python \
  scripts/run_asch.py \
    --driver engine \
    --condition C0 \
    --sessions 1 \
    --llm scripted \
    --policy random \
    --out runs \
    --run-id engine_smoke
```

各参数含义：

| 参数 | 取值 | 说明 |
|---|---|---|
| `--driver engine` | 必须 | 走 `socioverse.engine.build_simulator`，而非本地 standalone 循环 |
| `--condition C0` | 最简条件 | 独立作答，无同伴答案，无 C4 干扰段 |
| `--sessions 1` | 1 个会话 | 只跑 `C0-S01` |
| `--llm scripted` | 离线 | 不联网、不需要 key |
| `--policy random` | 盲策略 | 确定性伪随机作答，可复现 |

## 3. 预期输出

终端尾部应出现：

```text
C0-S01 C0 A1 critical_error=0.25 neutral_correct=0.5

wrote runs/engine_smoke/index.json (1 session(s), 0 failure(s))
```

**`0 failure(s)` 是唯一硬性通过标准。** 数值本身（0.25 / 0.5）是盲策略的确定性结果，
用于证明管线没编造数据，不表示任何行为发现。

# 3) DuckDB 轨迹库

`metrics.json` 只含 18 行试次指标（`t=0` 汇总行按 `trial_id` 过滤掉）。

## 5. 与本地桩的区别（避免混淆）

| | 本地桩 `--local-stub` | 真实引擎 `--driver engine` |
|---|---|---|
| 驱动 | `scripts/commshim.py` 假 socioverse | `socioverse.engine.build_simulator` |
| 输出标签 | `engineering validation only` | `engine run` |
| 轨迹库 | 无 | `trajectory/study.duckdb` |
| 能声称 | 仅管线自检 | 才算 SocioVerse2 运行 |

## 6. 常见问题

- **`ModuleNotFoundError: No module named 'socioverse'`**
  解释器里没装 SocioVerse2。用第 1 节的 venv，或 `pip install -e <checkout>`。

- **`KeyError: No environment registered under 'asch.env'`**
  provider 未注册。真实引擎路径需要先 `asch.register_providers()`（`run_asch.py` 的
  `run_via_engine` 已自动调用）；若手写脚本复现，记得先 import 运行时模块。

- **pydantic 校验报错（`Field required`）**
  `asch/bundles.py` 的 schema 与已安装 SocioVerse2 版本不匹配，检查版本后同步字段。

- **想跑带同伴的条件**
  把 `--condition C0` 换成 `C1`（一致错误多数），仍可用 `--llm scripted` 冒烟。
