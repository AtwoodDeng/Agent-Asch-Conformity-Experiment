# Asch 从众实验 —— 多智能体复现（SocioVerse2）

本项目按 Asch (1956) 的线段判断范式，在 SocioVerse2 平台上构造一个可运行、可审计、**不夸大结论**的从众实验。它复现的是范式的**结构**，而不是原始材料本身：18 个试次（12 关键 + 6 中性）、按座次公开作答、同盟者先答、固定被试连续完成全部判断。

> **先读这一段。** 本仓库的离线运行结果**不是**实验结果，只是管线自检。真实的引擎运行需要 SocioVerse2 运行时与可用的模型凭据，本机两者都没有。见"三类数字"一节。

## 快速开始

```bash
# 只用标准库之外的两个依赖
pip install pillow pytest

# 1. 生成刺激图像（74 张：3 套排列 × 18 + 20 张校准图）
python scripts/make_stimuli.py

# 2. 冻结设计与哈希
python scripts/freeze_hashes.py --version v1

# 3. 跑一次完整网格（离线、无模型调用）
python scripts/run_asch.py --local-stub --condition all --sessions 1-12 \
    --llm scripted --out runs --run-id grid1

# 4. 分析
python scripts/analyze.py --run runs/grid1 --export --boot 2000

# 5. 测试
python -m pytest tests/ -q
```

全部 93 个测试通过，不需要网络，不需要 API key。

`analyze.py --export` 产出 `trials.csv`（1,080 行）、`sessions.csv`（60 行）、
`analysis.json` 与 `SUMMARY.md`。报告覆盖 §9 要求的全部可产出部分：C0–C4 指标、
各会话轨迹、C2 正确同伴的影响（按异议座位拆分）、C4 相对 C1 的差异、
C4 信息流清单（每会话 17 个按序片段）、以及缺失情况清单。
"缺失情况"一栏把**未产出的交付物**与**未通过的数据完整性检查**分开列出，
两者语义不同，不互相掩饰。

## 三类数字，永不混用

这是本仓库最重要的一条纪律。任何一次运行产出的数字，必须归入且只归入以下三类之一：

| 类型 | 产生方式 | 可以说什么 | 不可以说什么 |
| --- | --- | --- | --- |
| **管线自检** | `--driver standalone` + `--llm scripted` | "证据链、评分、统计与报告流程无错误" | 任何关于人类从众心理的结论 |
| **模型行为** | 真实引擎 + `--llm openai` + 真实刺激图像 | "该模型在该约束下的作答分布" | 外推到人类群体 |
| **文献基线** | Asch 1956 原始数据 | 与历史结果的**参照**比较 | 与本项目的统计检验混算 |

`runs/grid1` 属于第一类。它的标签在 `index.json` 与 `SUMMARY.md` 中被硬编码为 `engineering validation only`，且 `analysis.py` 在 `driver == "standalone"` 时自动插入警告块。这不是注释礼貌，是防止截图外流后的误读。

### 为什么 grid1 的数字"看起来很平"是正确现象

grid1 的脚本策略是**故意盲的**：它不看线段，也不看他人答案，按固定规则作答。因此：

- 关键试次错误率在各条件间**应该**没有差异（实测 C4−C1 = −0.007，区间含零）；
- 中性试次正确率**应该**失败（实测约 1/3，`neutral gate passes: False`）。

这两点是管线**证明自己没有无中生有**的证据，不是缺陷。反过来，若一个盲策略跑出了显著差，那才是必须调查的 bug。

## 五个条件

| 条件 | 他人答案 | 说明 | 有无试次间干扰材料 |
| --- | --- | --- | --- |
| C0 | 不显示 | 独作答基线 | 无 |
| C1 | 6 人一致错误 | 经典从众条件 | 无 |
| C2 | 5 错 + 1 对 | 异议者存在于固定座位 | 无 |
| C3 | 6 人一致正确 | 反向对照 | 无 |
| C4 | 6 人一致错误 | C1 + 干扰材料 | 17 段 |

主要对比为 **C4 − C1**；次要对比 C0−C1、C1−C2、C1−C3。

**C4 的诚实声明**：它**不是**对 Asch 任何实验的复制。Asch Exp. 1 没有在试次间插入无关材料，因此 C4 的任何结果只能作为本项目的探索性构造，不可与 Asch 的数字并列陈述。

## 关键约束（实现中已机械化，不是约定）

- **答案键绝不进入决策模型。** `local_physical` 只含 prompt、图像路径、他人答案、座位。`check_no_key_leak()` 断言 6 个键字段不存在；`tests/test_pipeline.py` 在 5 个条件的每个试次上验证。
- **不出现条件标签与评价词。** 36 条禁止片段；被试可见文本中不出现 C0–C4、从众、同盟、正确、错误。
- **正反两个方向的诱导都被禁止。** 既不许"像普通人一样从众"，也不许"坚持独立判断"——后者是更隐蔽的污染。
- **不提供对错反馈、奖励或惩罚。**
- **干扰材料严格位于相邻试次之间**：17 段、18 试次、不截断、不追加 LLM 调用。
- **事后询问只问一次**，且不写回 history。
- **冻结配置带哈希**；`freeze_hashes.py --check` 发现漂移即失败，改内容必须升版本。

## 已知限制

这些限制**不是待办**，是需要在引用本项目时一并说明的边界：

1. **公开性是名义上的。** 只有一个 LLM 被试，"其他人"是写入提示词的字符串，不存在真实的社会在场。因此本范式能测的是"文本呈现的他人答案对作答的影响"，不是社会学意义上的公开压力。
2. **动机缺失。** 人类被试面对的是同伴压力；模型面对的是上下文。两者不可直接等价。
3. **C2 的座位不可能完全平衡。** 12 会话要覆盖排列（3）× 异议者座位（3），得到 9 个格子，无法整除；实测分布 2/2/2 加 6 个 1。这是设计约束的直接后果，不是错误。
4. **C4 的干扰材料仅增加约 216 token** 的输入量，其对比的效应量预期极小，现有样本量（12/条件）无法可靠检出；该对比只作探索性报告。
5. **样本量限制。** n=12/条件时，可检出效应量下限（MDE）约为绝对差 0.15；更小的差异不会被报告为"已解决"，而是"区间含零/低于 MDE"。
6. **校准门槛 95% 比 Asch 的 >99% 宽松**，这是为了容错图像解析，代价是更松的合格线。
