# 提示词措辞对照表

本表满足 `实验规划.md` §3.2 第 45 行的要求：在冻结提示词之前，逐条记录每处措辞的文献来源与改动理由。`asch/prompts.py` 中的字符串为唯一实现来源；本表是它的说明文档，不构成第二份实现。

## 一、判断依据的三种类型

本项目的措辞并非随意翻译。每一行都标注了它的依据类型：

| 标记 | 含义 |
| --- | --- |
| **原文** | 措辞直接来自 Asch 1956 报告或其实验程序的记录，见 `Docs/文献解析报告.md` |
| **转述** | 原文措辞过长或依赖现场口头情境，本项目压缩为一句，语义等价 |
| **适配** | 原文没有对应表述（例如 API 调用没有"房间"），按同一约束重新设计 |
| **本地** | 本项目自己的设计选择，文献中没有对应物，需要在下文单独交代理由 |

## 二、逐条对照

### 1. 任务说明（`COMMON_INSTRUCTION`）

| 项目 | 内容 |
| --- | --- |
| **原文依据** | 被试被告知的任务是判断一条标准线与三条比较线中哪一条长度相同（Asch 1956, Exp. 1 程序部分；`Docs/文献解析报告.md` §2） |
| **原文措辞** | 英文原文涉及"judge which of the three comparison lines is equal in length to the standard line" |
| **中文适配** | "判断三条比较线中哪一条与标准线长度相等" |
| **改动理由** | 中文保留"长度相等"这一操作定义，不使用"一样长"等口语表述，避免"一样"被读成视觉相似而非数值相等。原文没有说明"只看卡片还是可以拿起来量"，本项目也不作此说明，因为图像不提供物理操作。 |
| **依据类型** | 转述 |

### 2. 只回答 A、B、C（`TRIAL_QUESTION`）

| 项目 | 内容 |
| --- | --- |
| **原文依据** | 被试以口头方式说出选项，记录者转录（Exp. 1 程序） |
| **原文措辞** | 原文没有强制字母编号；字母 a–f 是**试次编号**，不是选项编号（见 `Docs/文献解析报告.md` §2 脚注说明） |
| **中文适配** | "只回答 A、B 或 C" |
| **改动理由** | 这是本项目**最大的适配点**，必须明确记录：字母在这里是**选项标签（A/B/C）**，与原文中 a–f 代表中性/关键试次的分组字母**完全不同**，两者不可混用。改用字母的原因是可解析性——自由文本会让解析失败率直接污染主要指标。此适配的代价是：假如原文被试有"被要求说字母"这一细节，本项目无法宣称逐字复现。 |
| **依据类型** | **本地**（且与原文的 a–f 用法存在同名异义风险） |

### 3. 公开作答的说明（`PUBLIC_ANSWERING_INSTRUCTION`）

| 项目 | 内容 |
| --- | --- |
| **原文依据** | 被试在公开场合依次作答，能听到前面成员的答案（Exp. 1 程序；Fig. 1 的座位安排） |
| **原文措辞** | 原文强调回答是"public"的、按固定座次进行 |
| **中文适配** | "参与者按照座位顺序依次作答，你的回答同样会被其他人听到。" |
| **改动理由** | 删去"听到"，因为接口不传递音频；改为"会被其他人听到"是一种**承诺**而非事实陈述——本项目实际上是文本转录。这一点在 README 的"14 公开性的边界"一节中列为已知限制。保留"座位顺序"是因为它是从众压力的结构化来源，也是 C2 异议者位置的前提。 |
| **依据类型** | 适配（并带有已声明的不精确） |

### 4. 此前参与者的回答（`PEER_BLOCK_HEADER`、`PEER_LINE`）

| 项目 | 内容 |
| --- | --- |
| **原文依据** | 被试听到前面 6 位成员的答案 |
| **原文措辞** | 原文以"majority"、"other members"指代，未使用"confederate" |
| **中文适配** | 标题"此前参与者的回答："；行格式"参与者 {seat}：{answer}" |
| **改动理由** | 三处刻意规避：① 不使用"同盟者/助手/假被试"，因为那会直接告知被试答案是被安排的；② 不使用"多数/少数"，因为那是对结果的描述而非现场信息；③ 使用中性词"参与者"并标注座位号，使每条答案可追溯身份——C2 的正确异议者必须能被识别为"某一个具体的人"，否则该条件不成立。 |
| **依据类型** | 转述 |

### 5. 不提对错（全局约束）

| 项目 | 内容 |
| --- | --- |
| **原文依据** | Asch 的程序没有对被试作答给出对错反馈 |
| **原文措辞** | 无对应表述 |
| **中文适配** | 全流程不出现"正确/错误/答对/答错" |
| **改动理由** | 一旦出现对错反馈，被试的后续作答就变成学习任务，从众率不再可比。此项由 `FORBIDDEN_FRAGMENTS` 机械保证（共 36 条），并由 `tests/test_pipeline.py::test_no_condition_labels_reach_the_subject` 在每个条件的每个试次上断言。 |
| **依据类型** | 原文（以禁止性约束实现） |

### 6. 事后询问（`DEBRIEF_PROMPT`）

| 项目 | 内容 |
| --- | --- |
| **原文依据** | Asch 在实验后访谈被试，询问其感受与是否察觉他人影响 |
| **原文措辞** | 原文的访谈是开放式、由研究者主持的 |
| **中文适配** | 一次性文本提问，要求被试说明作答时的想法 |
| **改动理由** | 采取三条硬约束：① **只问一次**，在全部 18 个试次结束后；② 结果单独存盘，**不写回 history**，否则它会成为后续试次的提示；③ 不设追问、不设二次确认，因为多轮追问本身会构成压力，可能诱发本不存在的从众。 |
| **依据类型** | 适配 |

### 7. 干扰材料（C4，`render_gap`）

| 项目 | 内容 |
| --- | --- |
| **原文依据** | **无**。Asch Exp. 1 没有在试次之间插入无关材料；本项目的 C4 是受其他从众研究启发的对照构造 |
| **原文措辞** | 不适用 |
| **中文适配** | 17 段与任务无关的中性短文，长度 60–100 字 |
| **改动理由** | 必须明确声明：C4 **不是**对 Asch 任何实验条件的复制。它的目的是提供一个"公开记录仍在、但注意力被稀释"的对照，用来检验从众是否依赖于对他人答案的持续注意。因为文献没有对应物，C4 的任何结果都只能作为本项目的探索性发现，不能与 Asch 的数字并列。 |
| **依据类型** | **本地（无文献对应，须在报告中单独标注）** |

## 三、禁止片段清单的作用

`asch/prompts.py` 中的 `FORBIDDEN_FRAGMENTS`（36 条）是上述规则的机械化。它的价值不在于"措辞好看"，而在于把三类最容易泄漏的字符串挡住：

1. **条件标签本身**（C0–C4、实验组、控制组）：泄漏条件即破坏盲性。
2. **对答案的评价**（正确、错误、多数、少数、从众、坚持）：把结果告诉被试。
3. **诱导性指令**（"像普通人一样从众"、"坚持独立判断"、"不要受别人影响"）：**正反两个方向都被禁止**。反向诱导（命令独立）同样会污染结果，且更隐蔽。

## 四、需要读者知道的两处不精确

诚实起见，以下两点在本表中保留而不掩饰：

- **"听到"是承诺而非事实**（第 3 条）。接口以文本传递答案，没有音频。若未来接入语音，此措辞才真正成立。
- **字母 A/B/C 与原文 a–f 同名异义**（第 2 条）。任何把本项目结果与 Asch 表格直接对齐的尝试，都必须先排除这一混淆。
